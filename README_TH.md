# Today Mood — เวอร์ชันฐานข้อมูลออนไลน์

โปรเจกต์เว็บแอปบันทึกอารมณ์ด้วย Supabase Auth + PostgreSQL พร้อม:
- สมัครสมาชิก / เข้าสู่ระบบด้วยอีเมลและรหัสผ่าน
- บันทึกอารมณ์ ระดับความเข้มข้น สาเหตุ และโน้ตส่วนตัว
- ดูและลบบันทึกของตัวเอง
- สรุปข้อมูลส่วนตัว
- หน้าผู้ดูแลแสดงเฉพาะสถิติรวม ไม่แสดงโน้ตหรือข้อมูลรายบุคคล

## สำคัญ: นี่คือชุดโค้ดที่เตรียมไว้ ไม่ใช่เว็บที่ deploy แล้ว
ต้องสร้างโปรเจกต์ Supabase ของตัวเองและนำ URL/key มาใส่ก่อน จึงจะบันทึกออนไลน์ได้

## วิธีติดตั้ง
1. สร้างโปรเจกต์ที่ https://supabase.com/
2. เปิด SQL Editor ใน Supabase แล้ววางและรันเนื้อหาไฟล์ `schema.sql`
3. ไปที่ Project Settings > API แล้วคัดลอก Project URL และ publishable/anon key
4. เปิด `config.js` แล้วแทนค่า:
   - `SUPABASE_URL`
   - `SUPABASE_ANON_KEY`
   ใช้ได้เฉพาะ publishable/anon key ฝั่ง browser เท่านั้น ห้ามใช้ `service_role` key
5. เปิด Authentication > URL Configuration และตั้ง Site URL/Redirect URLs ให้ตรงกับโดเมนที่นำเว็บไปวาง
6. นำไฟล์ `index.html`, `styles.css`, `app.js`, `config.js` ไปวางบน static hosting เช่น Netlify, Vercel หรือ GitHub Pages
7. เปิดเว็บ สมัครบัญชี แล้วทดสอบบันทึก/ลบ/ออกจากระบบและกลับเข้าสู่ระบบอีกครั้ง

## ตั้งค่าผู้ดูแล
1. สมัครบัญชีผ่านเว็บก่อน
2. ใน Supabase ไปที่ Authentication > Users แล้วคัดลอก UUID ของบัญชีผู้ดูแล
3. ใน SQL Editor รันคำสั่งนี้โดยแทน UUID จริง:
   `update public.profiles set role = 'admin' where id = 'YOUR-AUTH-USER-UUID';`
4. ออกจากระบบแล้วเข้าสู่ระบบใหม่ หน้าภาพรวมผู้ดูแลจะปรากฏ
5. อย่าเปิดช่องทางให้ผู้ใช้กำหนด role เอง

## ความเป็นส่วนตัว / ข้อจำกัด
- Row Level Security (RLS) จำกัดให้ผู้ใช้เข้าถึงได้เฉพาะบันทึกของตนเอง
- ผู้ดูแลเห็นเพียงจำนวนบัญชี จำนวนบันทึก และระดับเฉลี่ยรวม ผ่านฟังก์ชันที่ตรวจ role ฝั่งฐานข้อมูล
- ข้อความบันทึกอาจเป็นข้อมูลอ่อนไหว ควรจำกัดผู้ดูแลให้น้อยที่สุด แจ้งผู้ใช้ให้ชัดเจน และเก็บเท่าที่จำเป็น
- เวอร์ชันนี้ไม่มีการแก้ไขบันทึก ไม่มีลืมรหัสผ่านในหน้าเว็บ และไม่มีกราฟแนวโน้มเต็มรูปแบบ
- ควรเปิดการยืนยันอีเมลและตั้งค่าการป้องกันการสมัคร/อัตราการเรียก API ตามความเหมาะสม
- อย่าบันทึก secret/service_role key ใน frontend, Git หรือภาพหน้าจอ
- โค้ดนี้เป็น starter MVP ควรทดสอบนโยบาย RLS และการตั้งค่าก่อนใช้กับผู้ใช้จริง โดยเฉพาะเมื่อใช้ในงานวิจัยหรือกับนักเรียน
